## Editing rules

- Files here are **frozen verbatim** where noted. A correction to a historical record is
  appended as an addendum, not an edit.
- Internal path references inside the journal point to **post-refactor locations**
  (they were updated during the refactor) — the pre-refactor layout no longer exists by
  design.
